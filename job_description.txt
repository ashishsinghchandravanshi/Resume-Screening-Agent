Job Title: Senior Backend Software Engineer

Company: Aashirwaad Cloud Systems
Location: Bengaluru, India (Hybrid)

About the Role:
We are looking for a Senior Backend Software Engineer to design, build, and scale
the core services powering our cloud platform. You will work closely with product,
DevOps, and data teams to ship reliable, high-performance APIs and microservices.

Responsibilities:
- Design and build RESTful APIs and microservices using Python
- Write efficient, well-tested, production-grade code
- Work with relational and NoSQL databases (PostgreSQL, MongoDB)
- Deploy and manage services on AWS using Docker and Kubernetes
- Build and maintain CI/CD pipelines
- Collaborate with cross-functional teams in an Agile environment
- Mentor junior engineers and participate in code reviews
- Monitor system performance and troubleshoot production issues

Required Qualifications:
- Bachelor's degree in Computer Science, Engineering, or a related field
- 5+ years of professional software development experience
- Strong proficiency in Python; experience with Django or Flask
- Solid understanding of REST API design and microservices architecture
- Hands-on experience with SQL databases (PostgreSQL/MySQL)
- Experience with AWS (EC2, S3, Lambda, RDS)
- Experience with Docker and container orchestration (Kubernetes)
- Familiarity with CI/CD tools (Jenkins, GitHub Actions, GitLab CI)
- Proficient with Git and collaborative version control workflows
- Strong understanding of data structures, algorithms, and system design

Preferred Qualifications:
- Experience with message queues (Kafka, RabbitMQ)
- Exposure to NoSQL databases such as MongoDB or DynamoDB
- Familiarity with Terraform or other infrastructure-as-code tools
- Prior experience mentoring engineers or leading small project teams
- Master's degree in Computer Science or related field
- Experience with monitoring/observability tools (Prometheus, Grafana, ELK)
